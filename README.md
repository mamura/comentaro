# Comentaro

Comentaro é uma proposta de central de reputação e atendimento multicanal. A visão é acompanhar interações ligadas aos canais da organização e, futuramente, menções públicas externas. O MVP começa pelas interações diretamente associadas aos canais conectados.

O primeiro vertical é o de restaurantes, mas o domínio deve servir a outros tipos de negócio. A unidade central do produto é a `Interaction`.

## Estado do projeto

Esta etapa contém documentação e decisões arquiteturais iniciais. A aplicação ainda não foi implementada. A stack aprovada separa um backend Laravel modular de um frontend React, com contrato OpenAPI e PostgreSQL. Integrações e regras detalhadas continuam sendo validadas antes da implementação.
