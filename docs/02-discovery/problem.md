# Problema

Organizações que recebem avaliações, comentários ou outras interações em canais distintos podem perder contexto e demorar a perceber situações que exigem atenção. O Comentaro busca centralizar o acompanhamento e apoiar a decisão de responder.

Para o primeiro vertical, investigar como restaurantes acompanham hoje os canais, que tipos de interação importam, quanto tempo levam para responder e quais alertas seriam úteis.

Esta descrição é uma hipótese de problema. Entrevistas e observação do fluxo atual ainda são pendentes.
